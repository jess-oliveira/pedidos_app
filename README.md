# App de Pedidos

Projeto acadêmico desenvolvido em Python com foco na prática de:

- listas
- loops
- funções
- condicionais
- manipulação de dados
- organização de fluxo da aplicação

O sistema funciona via terminal e permite cadastrar, listar e remover pedidos utilizando menus interativos.

---

# 📚 Objetivo do estudo

O principal objetivo deste projeto foi praticar:

- estruturação de funções
- manipulação de listas aninhadas
- validação de entradas
- controle de fluxo com loops
- utilização de `match case`
- separação de responsabilidades básicas

Além disso, o projeto ajudou a desenvolver lógica de programação e organização inicial de aplicações em Python.

---

# ⚙️ Funcionalidades

O sistema permite:

- inserir novos pedidos
- listar pedidos cadastrados
- excluir último pedido
- validar opções do menu
- manter a aplicação em execução até o encerramento manual
